# Built Between Cases

Tools for anaesthesia and intensive care, built by clinicians, most of them with AI. Each one opened and checked, with its maker named.

Live at https://ganeshsivasankara.com/built-between-cases/

Curated by Dr Ganesh Sivasankara. To suggest a tool or a correction, write to ganesh@ganeshsivasankara.com.

The page is `index.html`. Every upload to this repository republishes it, and the link-preview picture and the phone picture for the My work page are redrawn automatically.

The fonts (Spectral, Red Hat Text and B612 Mono, SIL Open Font License) are stored in `fonts/`, so the page loads nothing from outside the site.
